# Sate-cembul
Sate Cembul menyajikan kelezatan sate kambing muda khas Tegal yang dibakar di atas bara arang alami. Dengan bumbu kacang gurih, potongan daging empuk, dan aroma bakaran yang menggoda, setiap tusuk sate menghadirkan cita rasa tradisi yang tetap hidup hingga hari ini. Nikmati pula suasana hangat warung sederhana kami di Bojong Minggir.
